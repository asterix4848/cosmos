# Contributing to Cosmos

Thank you for considering a contribution.

1. Open an issue first for substantial features or design changes.
2. Keep pull requests focused and explain the user-visible change.
3. For bug fixes, include steps to reproduce the problem and the environment (Linux distribution, Python version, and audio backend).
4. For visual changes, include a screenshot or short recording when possible.
5. Update the README when installation, controls, or audio behavior changes.
6. Keep dependencies small and document their purpose.

By submitting a contribution, you agree that it is provided under the project's MIT License.
